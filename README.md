# منهج حياة — موقع التطبيق

الموقع الرسمي لتطبيق «منهج حياة» للقرآن والصلاة والذكر.

من تصميم وتطوير **المهندسة ألاء بشير سيجري**. © 2026 جميع الحقوق محفوظة. التفاصيل في [LICENSE](LICENSE).

هذا المستودع يضم ملفات الموقع فقط. تنشره `.github/workflows/deploy.yml` على GitHub Pages، وتجلب معه آخر إصدار من ملفات التطبيق.

- الصفحات الداخلية (الميزات ودليل التثبيت والصفحة الإنجليزية وخريطة الموقع) تُولَّد من `tools/build_pages.py`: عدّل النص هناك ثم شغّل `python3 tools/build_pages.py`.
- `assets/download.js` هو كود زر التحميل (التقدّم والعدّاد) المشترك بين كل الصفحات.
